## 2. 核心成果

### 2.1 Skill 引擎（A 轨）

配置驱动、零 Java 新增能力：
- `SkillRegistry` 扫描 `classpath:skills/*/skill.yaml` 自动注册
- 6 个 skill：topic-gen / proofreading / article-to-x / research / seo-optimizer / content-translator
- **HITL 多轮确认**：approve / modify / retry 三动作
  - `retry` 通过 `updateState` 清除阶段输出重跑，上游结果保留（不白烧 token）
- **ModelRouter**：agnes 默认 + dashscope 降级
- **链式编排**：前一个输出透传为后一个输入，前端可视化

### 2.2 文章增强（B 轨）

- **五维质量评分**：结构/逻辑/语言/SEO/可读性
- **多轮改写 + 版本历史**：快照 + 回退 + diff-base
- **多格式导出**：PDF（OpenPDF）/ Word / PPTX（Apache POI）
- **文章模板** 实体 + 预设

### 2.3 平台化（C 轨）

- **协作空间**：owner/admin/member/viewer 角色层级
- **审批流**：submit → admin approve/reject（作者不能自审）
- **定时发布**：`@Scheduled` 到期自动发布，发布前复核审批状态
- **分析仪表盘**：风格/配图/质量趋势/技能/模型/活跃度聚合
- **Webhook**：HMAC-SHA256 签名 + SSRF 防护 + 5 次指数退避重试
- **i18n**：Accept-Language 协商，zh/en 双语

### 2.4 基础设施（D 轨）

- **Docker** 多阶段构建 + docker-compose（MySQL+Redis+Backend）
- **Redis 缓存** 三级 TTL + **@RateLimit** 注解（Redis→内存降级）
- **Micrometer** 指标（LLM 调用/配额/Skill/文章）
- **熔断器**（轻量 ConcurrentHashMap 实现，无额外依赖）
- **CI/CD** GitHub Actions（mvn verify + Docker build）

### 2.5 方法论模块

- `MethodologyDefinition/Registry`：从 YAML 加载创作方法论
- `MethodologyPromptAssembler`：标题策略 + 创作维度引导段注入
- 双路径注入（StateGraph + 传统串行），不破坏结构化输出

## 3. 工程规范

### 3.1 提交规范（Conventional Commits）

- `CONTRIBUTING.md`：type 枚举 / scope 小写 / subject 50-72 / 祈使句 / BREAKING CHANGE / revert
- `.githooks/commit-msg`：bash 钩子强制 50/72 + type 白名单 + revert 校验（无 node 依赖）
- `.github/pull_request_template.md`：Done 标准 + 安全自查
- 审计：16 个新提交 100% 格式合规

### 3.2 安全实践

| 风险 | 修复 |
|------|------|
| IDOR | 所有新端点增加归属校验 |
| 授权绕过 | approve/reject 提升为 admin |
| Prompt 注入 | SystemMessage 角色隔离 |
| SSRF | Webhook URL 校验（仅 https + 拒绝内网 IP） |
| 硬编码密钥 | 全部 `${VAR:}` 外部化 + fail-fast |
| fail-open | RateLimit 故障时内存降级 |

## 4. 技术挑战与解决方案

| 挑战 | 解决方案 |
|------|----------|
| StateGraph 跨 ClassLoader 类型转换 | className 比较 + Gson 深拷贝 |
| HITL 续跑从 START 重跑 | 必须用带 checkPointId 的 config |
| 多确认点 TTL 提前耗尽 | settle() 二次暂停时刷新注册时间 |
| retry 重跑当前阶段 | updateState 清除该阶段 outputKey |
| 终态后取不到 SkillContext | getPersistedOutput 从 DB 读回 |
| 测试 H2 空库 | test/resources 引用 classpath:sql/h2-schema.sql |
| vue-tsc Windows 崩溃 | type-check 单独跑 + build-only（环境问题） |
