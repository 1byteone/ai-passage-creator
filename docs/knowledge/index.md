# 当前项目研发知识库

本目录是当前项目研发知识库的 Git 事实源，服务范围限定为 `ai-passage-creator`。

## 使用规则

- 稳定规范、业务规则、开发计划、测试证据和架构决策必须和代码一起提交并评审。
- 未确认的内容标记为“待确认”，不能被 AI 当作强制规则。
- 计划不是完成证明；完成状态必须有代码、测试命令和版本证据。
- 手工上传文档只能作为 `pending_review` 草稿，审核通过后回写 Git。

## 知识域

- `standard`：技术栈、目录边界、组件和安全质量规范。
- `business`：模块流程、角色、状态、不变量和业务限制。
- `development`：实现顺序、接口契约、迁移、联调和回滚。
- `testing`：测试矩阵、正常流、异常流、环境、数据和证据。
- `decision`：ADR 架构决策、权衡、后果和复审条件。

## 当前事实源

首批同步范围包括根目录 `AGENTS.md`、`CLAUDE.md`、`PROJECT_ARCHITECTURE.md`、`CONTRIBUTING.md`、`DEPLOYMENT.md`、`README.md`，以及本目录下的 Markdown 文件。同步接口只读，不会修改 Git 或生产数据。
