## 3. 当前已确认的全局问题

### 3.1 信息架构

1. 首页仍有较强模板 Hero 和泛能力卡片结构，真实证据区不足。
2. 创作页固定三栏在桌面可承载信息，但主工作区和辅助信息竞争注意力。
3. 移动端创作页此前通过隐藏左右侧栏解决空间问题，关键上下文会丢失。
4. Skill 执行页结构已经较清晰，但执行前“输入什么/得到什么”的任务预期仍可更明确。
5. 统计页图表先于解释，移动端需要更强摘要和降级策略。

### 3.2 视觉系统

1. 已开始将绿色主题升级为语义化 token，但页面级迁移尚未完成。
2. 局部页面仍有较多卡片、悬浮和渐变表达，后续需要按页面任务收敛。
3. 首页 `hero-title` 仍使用渐变文字和负字距，需要在首屏重构中评估是否保留。

### 3.3 交互与状态

1. 全局 `focus-visible` 已统一落第一版，但页面级键盘路径还没有逐页验收。
2. 创作页明显 emoji 状态表达已清理第一批，但文案语气还需继续统一。
3. 流式内容区域需要继续做稳定容器，减少布局跳动。

### 3.4 性能

1. `npm run build` 已通过。
2. 构建提示 `StatisticsPage` 和主入口 `index` chunk 超过 500 kB。
3. 图表依赖与首屏入口依赖需要后续进入 `FP-P0-16` 拆包治理。

## 4. 断点审计计划

后续视觉验收必须覆盖：

1. `375px`：小屏手机
2. `768px`：平板/大手机
3. `1024px`：小桌面/横屏平板
4. `1440px`：常规桌面

当前已完成代码审计，截图验收待运行本地服务后补齐。每个断点需要检查：

1. 是否有横向滚动
2. 主 CTA 是否清晰
3. 文本是否溢出或遮挡
4. 关键上下文是否丢失
5. 焦点样式是否可见
6. 异步内容是否造成明显跳动
