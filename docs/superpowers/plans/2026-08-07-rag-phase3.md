# RAG 阶段三实现计划：质量监控面板

> **For agentic workers:** 读此文件执行，每步 TDD。

**Goal:** 在 AnalyticsPage 加 RAG 质量监控区块，让 admin 可视化检索命中率、热门查询词、阶段分布。

**Architecture:** 扩展 `AnalyticsVO` 加 RAG 字段 → `AnalyticsService` 注入 `RagReferenceMapper` 做聚合 → 前端 AnalyticsPage 加 RAG 区块（metric-card + ECharts pie + a-table）。

**Tech Stack:** Spring Boot 3.5 / MyBatis-Flex / ECharts 6 / AntDV4。

## Global Constraints

- MyBatis-Flex `QueryWrapper`（非 Plus）；`paginate` 返回 `Page<T>`
- `rag_reference` 表：`stage(title/outline/content)`, `ref_type`, `score`, `create_time`
- 无 `RagReferenceMapper` 自定义 SQL（仅 BaseMapper）——需要加或直接用 QueryWrapper
- AnalyticsService 当前全量 stream 聚合（无分页）——RAG 统计保持同样模式
- AnalyticsPage 风格：自定义 `.metric-card` + `.chart-card`（不用 a-card），ECharts tree-shaking
- `AnalyticsVO` 已有字段保持向后兼容（新增字段可选）
- 前端 TS strict、SCSS scoped

- [ ] **Step 4: AnalyticsService 注入 + 聚合**

在 `AnalyticsService` 加 `RagReferenceMapper` + `RagService` 依赖。在 `buildAnalytics()` 末尾加：

```java
// RAG 统计
List<RagReference> allRefs = ragReferenceMapper.selectListByQuery(
        QueryWrapper.create().select("stage", "ref_type", "score", "create_time"));
if (!allRefs.isEmpty()) {
    vo.setRagTotalReferences((long) allRefs.size());
    vo.setRagAvgScore(allRefs.stream().mapToDouble(RagReference::getScore).average().orElse(0.0));
    vo.setRagStageDistribution(allRefs.stream().collect(groupingBy(RagReference::getStage, counting())));
    vo.setRagRefTypeDistribution(allRefs.stream().collect(groupingBy(RagReference::getRefType, counting())));
    // 热门查询词（按 refId 聚合，取 top 10）
    vo.setRagHotQueries(allRefs.stream()
            .collect(groupingBy(RagReference::getRefId, counting()))
            .entrySet().stream().sorted(Map.Entry.<String, Long>comparingByValue().reversed())
            .limit(10).map(e -> new AnalyticsVO.RagHotQuery(e.getKey(), e.getValue(), 0.0, ""))
            .toList());
}
```
