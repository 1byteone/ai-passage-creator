# AI Passage Creator P0 页面 IA 重排方案

> 日期：2026-07-25
> 对应任务：`FP-P0-02 输出首页/创作页/Skill 执行页 IA 重排方案`
> 状态：P0 结构方案已冻结，可进入页面实现。

---

## 1. IA 总原则

本轮 IA 重排遵循 5 条原则：

1. 回访用户优先，但首访用户不能迷路
2. 每个页面只保留一个主 CTA
3. 辅助信息可以折叠，但不能在移动端直接消失
4. 证据必须来自真实工作流、真实结果或真实数据
5. 页面结构先服务任务完成，再服务视觉表达

---

## 2. 首页 IA

### 2.1 页面任务

首页的主任务是让回访用户更快继续创作，同时让首访用户快速理解产品。

### 2.2 首屏结构

推荐顺序：

1. 产品名：`AI 爆款文章创作器`
2. 一句话价值：说明它如何帮助用户完成内容创作
3. 主 CTA：`继续创作` 或 `开始创作`
4. 次 CTA：`查看 AI 工具`
5. 真实工作流暗示：最近文章、示例结果、创作流程预览任选其一

### 2.3 登录态差异

已登录用户：

1. 最近创作或继续任务前置
2. 快捷 Skill 保持首屏附近
3. 入口文案更偏“回到任务”

未登录用户：

1. 产品解释更前置
2. 主 CTA 引导开始创作或登录
3. 证据区展示创作结果样例

### 2.4 区块任务

| 区块 | 工作 |
| --- | --- |
| Hero | 说明产品和主动作 |
| 回访入口 | 让已登录用户快速继续任务 |
| Skill 工具带 | 给高频专项任务入口 |
| 证据区 | 展示真实流程或结果 |
| 能力区 | 解释能力，但不做泛卖点堆叠 |

---

## 3. 创作页 IA

### 3.1 页面任务

创作页的主任务是完成一次从选题到成文的 AI 创作流程。

### 3.2 桌面结构

推荐结构：

1. 主工作区：输入、阶段内容、确认、结果
2. 左辅助区：流程进度，可收起
3. 右辅助区：配额、提示、日志、当前选题，可收起

### 3.3 移动结构

推荐结构：

1. 主工作区全宽
2. 当前步骤摘要固定在主内容上方
3. 配额、选题、提示、日志进入移动辅助面板
4. 日志只展示最近几条，完整日志可后续做抽屉

### 3.4 输入态结构

用户已选择“中等复杂度，一屏完成”，因此输入区应保持：

1. 选题输入
2. 文章风格
3. 配图方式
4. 配额和权限提示
5. 主 CTA

不要强拆多步，但需要清晰分组。

### 3.5 状态区规则

| 状态 | 必须说明 |
| --- | --- |
| INPUT | 要输入什么、还缺什么、能否开始 |
| TITLE_GENERATING | 当前正在生成标题，等待原因 |
| TITLE_SELECTING | 需要用户确认标题 |
| OUTLINE_GENERATING | 当前正在生成大纲 |
| OUTLINE_EDITING | 需要用户确认大纲 |
| CONTENT_GENERATING | 正在生成正文和配图 |
| COMPLETED | 结果已生成，下一步可复制、查看、再创作 |
| ERROR | 失败原因和恢复动作 |

## 4. Skill 执行页 IA

### 4.1 页面任务

Skill 执行页的主任务是完成一次专项 AI 工具调用，并得到结构化结果。

### 4.2 页面结构

推荐顺序：

1. 返回路径
2. Skill 名称与任务说明
3. 输入表单
4. 执行进度
5. 结果视图
6. 复制、回看、继续动作

### 4.3 输入区规则

1. 一屏完成输入
2. 字段帮助贴近字段
3. 默认值明确
4. 必填与错误状态清晰

### 4.4 执行区规则

1. 进度以阶段呈现，不制造虚假百分比
2. 流式预览只作为辅助，不抢结果主位
3. SSE 失败时有恢复路径

### 4.5 结果区规则

1. 结构化结果优先
2. 复制动作固定清晰
3. 未知 Skill 用安全回退视图
4. 嵌入态和独立页保持同一逻辑

---

## 5. 第一批实现切入点

根据 IA，第一批实现应从低风险但高收益的位置切入：

1. 创作页移动端辅助面板
2. 首页回访入口前置
3. Skill 执行页输入/进度/结果视觉分隔增强
4. 流式容器稳定化

本轮先落地第 1 项，后续继续推进第 2 项。
