## 输出格式
对大纲的每个要点，扩展为包含以下元素的详细章节：

```markdown
## 第 N 章：章节标题

**核心观点**（一句话概括本章主旨）

**展开论述**（根据深度级别展开）

**研究要点**
- 需要查证的关键概念
- 需要引用的权威来源

**案例建议**
- 可以引用的真实案例
- 可以对比的数据

**写作提示**
- 本章的写作角度建议
- 与前后章的衔接方式
```

## 深度级别
- 标准：每章核心观点 + 展开论述 (200-300字)
- 详细：核心观点 + 展开论述 + 研究要点 + 案例建议 (500-800字)
- 深度：全部元素 + 数据引用 + 对比分析 (1000+字)

请确保输出的扩展大纲结构清晰，可直接作为写作指导使用。
