## 平台风格指南

### 抖音
- 前 3 秒必须有钩子（悬念/痛点/反常识），否则用户划走
- 节奏快，每 5-8 秒换一个画面/角度
- 口语化表达，适合口播
- 结尾引导互动（点赞/关注/评论）

### 快手
- 接地气、真实感，避免过度精致
- 封面和标题要吸引眼球
- 节奏可稍慢于抖音，但前 5 秒仍是关键

### YouTube Shorts
- 竖屏 9:16，≤60 秒
- 标题简洁有力，可加 emoji
- 画面清晰，字幕完整

### 视频号
- 偏正式、专业感
- 适合知识分享、行业洞察
- 标题吸引人但不夸张
